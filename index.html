Documentación de EnginePlugins

Especificaciones técnicas y guía de configuración desarrollada por sasukelol21.

EnginePlugins es una suite modular orientada al rendimiento para servidores Paper, Purpur y Spigot. El código está diseñado de forma asíncrona, preparado para Java 25 y compatible con Minecraft 1.21.x hasta 26.3.

ChatEngine (v1.3.0)

Canales de chat, menciones directas con audio (@Player), filtros de moderación y formato RGB.

GUIEngine

Motor base e interfaz de inventarios optimizado para la creación de menús interactivos.

PollEngine (v2.0.0)

Encuestas interactivas con interfaz gráfica (GUI), conteo en vivo y anuncio automático de ganadores.

MotdEngine (v2.0.0)

Lista de servidores con rotación asíncrona, menú hover multilínea y modo mantenimiento.

Estructura y Diseño

  • Sin dependencias externas: Plugins autónomos listos para colocar en la carpeta plugins/.
  • Formato universal: Soporte de sintaxis MiniMessage y códigos tradicionales con ampersand (&).
  • Bajo consumo: Las tareas de parseo y cálculo corren fuera del hilo principal del servidor.

Instalación

Requisitos de entorno y proceso de despliegue.

Requisitos

  • Minecraft: 1.21.x – 26.3
  • Software: Paper (recomendado), Purpur, Spigot
  • Java Runtime: Java 25 (o Java 21)

Instalación

  1. Descarga el archivo .jar desde el repositorio oficial en Modrinth.
  2. Mueve el archivo al directorio plugins/ de tu servidor.
  3. Inicia el servidor para generar los archivos de configuración predeterminados.
  4. Modifica los archivos config.yml según las necesidades de tu red.
Toolchain Java 25: Compilado con bytecode version 69, garantizando compatibilidad nativa con Minecraft 26.3.

ChatEngine

Gestor de chat con canales, menciones y moderación (v1.3.0).
Descargar ChatEngine en Modrinth ↗

Características

  • Canales: Soporte de ámbitos GLOBAL, WORLD o personalizados en channels.yml.
  • Menciones: Etiqueta jugadores con @Nombre, aplicando resaltado y alerta de sonido.
  • Filtros: Detección de enlaces, palabras restringidas y control de repetición.
  • LuckPerms: Consulta prefijos, sufijos y grupos primarios en tiempo real.
  • Java 25 Nativo: Arquitectura asíncrona compatible con Minecraft 1.21.x hasta 26.3.

Comandos

Comando Permiso Función

Configuración Principal (config.yml)

Archivo de configuración generado automáticamente en plugins/ChatEngine/config.yml:

# ==========================================
# ChatEngine - Configuración Principal (config.yml)
# ==========================================

chat:
  # Canal por defecto al que se conectan los jugadores al entrar
  default-channel: global

  # Cancela el chat vanilla de Bukkit para procesarlo mediante ChatEngine
  cancel-vanilla-chat: true

  # Formatos de chat (Prioridad: by-group > by-world > default)
  formats:
    # Formato general por defecto
    default: "{prefix}{player}{suffix}&7: &f{message}"

    # Formatos específicos por mundo (usa el nombre interno de la carpeta del mundo)
    by-world:
      world: "&7[&aSurvival&7] {prefix}{player}{suffix}&7: &f{message}"
      world_nether: "&7[&cNether&7] {prefix}{player}{suffix}&7: &f{message}"
      world_the_end: "&7[&dTheEnd&7] {prefix}{player}{suffix}&7: &f{message}"

    # Formatos por grupo de LuckPerms (usa el primary group del jugador)
    by-group:
      default: "&7[&fUsuario&7] {prefix}{player}{suffix}&7: &f{message}"
      vip: "&7[&aVIP&7] {player}{suffix}&7: &f{message}"
      admin: "&7[&cAdmin&7] {player}{suffix}&7: &f{message}"

  # Control de permisos para colores en el chat
  colors:
    use-permissions: true      # Si es false, cualquiera puede usar colores
    allow-magic: false         # Desactiva &k para evitar abusos visuales

    legacy:
      enabled: true
      permission: "chatcolor.color.legacy" # &0-&f

    hex:
      enabled: true
      permission: "chatcolor.color.hex"    # &#RRGGBB o <#RRGGBB>

    formats:
      bold:
        enabled: true
        permission: "chatcolor.format.bold"      # &l
      italic:
        enabled: true
        permission: "chatcolor.format.italic"    # &o
      underline:
        enabled: true
        permission: "chatcolor.format.underline" # &n
      strikethrough:
        enabled: true
        permission: "chatcolor.format.strike"    # &m
      magic:
        enabled: false
        permission: "chatcolor.format.magic"     # &k

# Módulo de protección Anti-Spam
spam:
  enabled: true
  cooldown-seconds: 2          # Segundos mínimos entre cada mensaje
  repeat-window-seconds: 5     # Ventana para bloquear el envío del mismo mensaje

  bypass-permissions:
    cooldown: "chatengine.bypass.cooldown"
    repeat: "chatengine.bypass.repeat"

Configuración de Canales (channels.yml)

Permite definir canales de chat independientes en plugins/ChatEngine/channels.yml:

# ==========================================
# ChatEngine - Canales (channels.yml)
# ==========================================

channels:
  global:
    # Ámbito: GLOBAL (todo el servidor) o WORLD (solo jugadores en el mismo mundo)
    scope: GLOBAL
    permission-speak: "chatengine.channel.global.speak"
    permission-view: "chatengine.channel.global.view"
    format: "&7[&aGlobal&7] {prefix}{player}{suffix}&7: &f{message}"

  world:
    scope: WORLD
    permission-speak: "chatengine.channel.world.speak"
    permission-view: "chatengine.channel.world.view"
    format: "&7[&b{world}&7] {prefix}{player}{suffix}&7: &f{message}"

  staff:
    scope: GLOBAL
    permission-speak: "chatengine.channel.staff.speak"
    permission-view: "chatengine.channel.staff.view"
    format: "&c[StaffChat] &f{player}&7: &e{message}"

GUIEngine

Framework de interfaces de inventario y menús interactivos.
Descargar GUIEngine en Modrinth ↗

Características

  • Motor de Menús Seguro: Previene la extracción, duplicación o movimiento indebido de ítems en interfaces.
  • Renderizado de Componentes: Soporte directo de texto Adventure y MiniMessage en nombres y descripciones.
  • Modular: Diseñado para servir como base para sistemas de tiendas, selección de modalidad y votaciones.
  • Gestión de Eventos Automática: Cancelación de eventos no deseados en clics rápidos o atajos de teclado (números del hotbar, drop, shift-click).

Compatibilidad de Versiones

Versión Plugin Versiones Minecraft Soportadas Java Estado
1.0.0 (Core) 1.21.x – 26.3 (Paper, Purpur, Spigot) Java 21 – 25+ Estable

Seguridad y Protección Antidupe

GUIEngine implementa una capa estricta de validación sobre el ciclo de vida de los inventarios de Spigot/Paper:

  • Cancelación Obligatoria: InventoryClickEvent y InventoryDragEvent están blindados para evitar que los jugadores saquen ítems decorativos.
  • Control de Cierre: Manejo seguro con InventoryCloseEvent para limpieza de memoria y eliminación de listeners temporales.
  • Prevención de Clicks Fantasma: Verificación de identificadores únicos (UUID) por sesión de menú.

Ejemplo de Integración (API para Desarrolladores)

Ejemplo de creación de un menú interactivo protegido con callbacks usando la API de GUIEngine:

// Creación de un menú de 27 slots (3 filas)
GUIEngineMenu menu = new GUIEngineMenu("Menú Principal", 27);

// Configuración de un botón interactivo
ItemStack item = new ItemBuilder(Material.COMPASS)
    .name("&a&lSelector de Modalidades")
    .lore("&7Haz clic para abrir el menú de servidores.")
    .build();

menu.setItem(13, item, (player, clickType) -> {
    player.sendMessage("§aAbriendo servidor Survival...");
    player.closeInventory();
});

// Relleno estético de bordes
menu.fillBorders(Material.BLACK_STAINED_GLASS_PANE);

// Apertura segura para el jugador
menu.open(player);

PollEngine

Sistema de encuestas interactivas con interfaz gráfica (v2.0.0).
Descargar PollEngine en Modrinth ↗

Características

  • Interfaz GUI Interactiva: Los usuarios votan haciendo clic en el menú sin tener que escribir comandos complejos.
  • Temporizador y Anuncio Automático: Cuenta atrás configurable con anuncio en el chat y pantalla al terminar.
  • Cambio de Voto Flexible: Opción para permitir a los jugadores rectificar su elección mientras la encuesta siga activa.
  • Recuento en Vivo: Consulta los porcentajes y votos totales en cualquier momento con /poll results.

Configuración Principal (config.yml)

Configuración completa con soporte de sonidos, mensajes y temporizador en plugins/PollEngine/config.yml:

# ==========================================
# PollEngine - Configuración Principal (config.yml)
# ==========================================

settings:
  # Título que se muestra en la interfaz gráfica del menú de votación
  # Admite etiquetas MiniMessage (, , etc.)
  gui-title: "PollEngine | Votación"
  
  # Duración predeterminada de la encuesta en segundos al crearla sin especificar tiempo
  # (0 = duración ilimitada, se cierra manualmente con /poll end)
  default-duration-seconds: 120
  
  # Si es true, los jugadores pueden cambiar su voto mientras la votación siga abierta
  allow-change-vote: true
  
  # Efectos de sonido en acciones (nombres de sonidos de Bukkit, dejar vacío para desactivar)
  sounds:
    open-menu: "BLOCK_CHEST_OPEN"
    vote-success: "ENTITY_PLAYER_LEVELUP"
    vote-already: "ENTITY_VILLAGER_NO"
    poll-start: "ENTITY_EXPERIENCE_ORB_PICKUP"
    poll-end: "UI_TOAST_CHALLENGE_COMPLETE"

# Mensajes del sistema
messages:
  prefix: "PollEngine | "
  no-permission: "No tienes permiso para ejecutar este comando."
  no-active-poll: "No hay ninguna encuesta activa en este momento."
  already-voted: "Ya has votado por: {option}."
  vote-changed: "Tu voto ha sido actualizado a: {option}."
  vote-registered: "¡Gracias por votar! Tu opción: {option}."
  poll-created: "¡Una nueva encuesta ha comenzado!Pregunta: {question}Usa /poll para votar."
  poll-ended-broadcast: "¡Encuesta Finalizada!Pregunta: {question}Ganador: {winner} ({winner_votes} votos)"
  poll-results-header: "--- Resultados de la Encuesta ---Pregunta: {question}Total de votos: {total_votes}"
  poll-results-entry: "  {option}: {votes} votos ({percent}%)"
  config-reloaded: "Configuración de PollEngine recargada correctamente."

Creación de Encuestas

Sintaxis del comando para administradores:

/poll start <Pregunta> | <Opción 1> | <Opción 2> ... [segundos]

# Ejemplo con 2 opciones y 60 segundos:
/poll start ¿Reiniciar el mundo Nether? | Sí | No 60

# Ejemplo con 3 opciones y 120 segundos:
/poll start ¿Qué evento prefieres el sábado? | PvP Arena | Parkour | Spleef 120

MotdEngine

Personalizador de servidor, lista de jugadores y mantenimiento (v2.0.0).
Descargar MotdEngine en Modrinth ↗

Modos de Operación

  • ROTATING: Rotación periódica asíncrona cada X segundos.
  • RANDOM: Selecciona un mensaje al azar en cada ping.
  • STATIC: Muestra un único mensaje fijo.

Configuración Principal (config.yml)

Configuración completa para MOTD, hover de jugadores y mantenimiento en plugins/MotdEngine/config.yml:

# ==========================================
# MotdEngine - Configuración Principal (config.yml)
# ==========================================

# Configuración del mensaje en la lista de servidores
motd:
  # Modos disponibles:
  # - "ROTATING": Rota cíclicamente los mensajes cada X segundos
  # - "RANDOM": Elige un mensaje al azar en cada ping de un jugador
  # - "STATIC": Muestra siempre el primer mensaje de la lista
  mode: "ROTATING"

  # Intervalo de rotación en segundos cuando el modo es ROTATING
  rotation-interval-seconds: 15

  # Lista de mensajes MOTD (Usa \n o  para separar línea 1 y línea 2)
  # Soporta MiniMessage (, , ) y códigos clásicos (&a-&f)
  messages:
    - "¡Bienvenido a Nuestro Servidor!\nSurvival Custom, Minijuegos & Creativo • ¡Únete ya!"
    - "La Mejor Experiencia Minecraft\nEventos especiales de fin de semana activos • Juega con amigos"
    - "Actualizado a la última versión 26.3!\nRendimiento óptimo sin lag • ¡Te esperamos!"

# Personalización del recuento de jugadores y slots
player-count:
  # Si es true, sobrescribe el límite de jugadores del server.properties
  override-max-players: false
  # Límite estático de jugadores (si override-max-players es true y dynamic-max es false)
  max-players: 100
  # Si es true, el máximo siempre será (jugadores_conectados + dynamic-addition)
  dynamic-max: true
  dynamic-addition: 1

# Menú emergente al pasar el ratón sobre el recuento de jugadores
player-hover:
  enabled: true
  lines:
    - "--- INFORMACIÓN DEL SERVIDOR ---"
    - "Jugadores en línea: {online} / {max}"
    - "Comunidad Discord: discord.gg/tuservidor"
    - "Tienda Oficial: tienda.tuservidor.net"
    - "¡Que disfrutes de tu estancia!"

# Sistema de Modo Mantenimiento
maintenance:
  enabled: false
  # MOTD mostrado cuando el mantenimiento está activo
  motd: "SERVIDOR EN MANTENIMIENTO\nVolveremos en breve. Consulta nuestro Discord para más noticias."
  # Mensaje de desconexión al intentar entrar sin permiso de bypass
  kick-message: "¡El servidor se encuentra actualmente en mantenimiento!Por favor, inténtalo más tarde o visita nuestro Discord."
  # Texto que reemplaza el número de versión en el cliente de Minecraft
  custom-version-text: "Mantenimiento"

# Mensajes del plugin
messages:
  prefix: "MotdEngine | "
  no-permission: "No tienes permiso para ejecutar este comando."
  config-reloaded: "¡Configuración de MotdEngine recargada correctamente!"
  maintenance-toggled: "El modo mantenimiento ahora está: {status}"
  maintenance-on: "ACTIVADO"
  maintenance-off: "DESACTIVADO"
  motd-set: "MOTD estático establecido: {motd}"

Preguntas Frecuentes

Resolución de dudas frecuentes.

¿Cómo configurar el acceso durante el mantenimiento?

Asigna el permiso motdengine.maintenance.bypass mediante tu plugin de permisos al grupo de administradores.

¿Se puede permitir el cambio de voto?

Sí, la clave allow-change-vote en el archivo config.yml de PollEngine habilita o deshabilita esta opción.
